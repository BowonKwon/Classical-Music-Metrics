Performance metricsUnit: MIDI velocity

Dynamic spread

Standard deviation of key-strike velocity (MIDI velocity, 0–127) within a performance.

Formula
per performance sd(velocity); piece value is the median across performances
How to read it
About 11 for Bach's Well-Tempered Clavier, about 17 for Beethoven sonatas — wider dynamic contrast in Beethoven.
Caveats
MIDI velocity is a proxy for loudness and its scale depends on instrument and setup. Use only for relative comparison within the dataset.
