Top-line leap ratio

At a glance

What the data show
Among the collections, Beethoven's piano sonatas have the highest median (0.501) and Bach's chorales the lowest (0.140). Within the piano sonatas: Beethoven 0.501, Mozart 0.419.
Watch for
The 'top line' is the chain of highest notes, not a designated voice, so it can differ from the true melody where voices cross.

Share of moves in the top line that span a minor third or more.

Formula
top line = highest sounding note at each onset position; tied notes keep sounding for their merged length, and a position is kept only where that highest note itself starts there. moves ≥ 3 semitones / all moves Grace notes are left out, and a tied continuation is merged into the note it continues and counted once. A continuation whose preceding note cannot be found is not counted as a new note (it remains a sounding note only for the top-line metrics).
How to read it
Chorale sopranos are nearly all stepwise (median 0.14); arpeggiated solo works reach 0.42 and Beethoven's sonatas 0.50.
Caveats
The 'top line' is the chain of highest notes, not a designated voice, so it can differ from the true melody where voices cross. When notes of the same highest pitch overlap, the one ending first is taken, and a re-struck note of that pitch in the meantime is skipped; a different tie rule changes some movement values slightly.
