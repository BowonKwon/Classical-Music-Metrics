Mean note length

At a glance

What the data show
Among the collections, Bach's chorales have the highest median (0.92) and Bach's solo works (violin, cello, flute) the lowest (0.45). Within the piano sonatas: Beethoven 0.59, Mozart 0.49.
Watch for
Tempo is unknown, so this is not time in seconds.

Average length of one note (quarter note = 1).

Formula
mean(note length after merging ties) Grace notes are left out, and a tied continuation is merged into the note it continues and counted once. A continuation whose preceding note cannot be found is not counted as a new note (it remains a sounding note only for the top-line metrics).
How to read it
0.5 means an eighth note on average. Bach chorales 0.92 (close to a quarter), solo works 0.45, Mozart sonatas 0.49, Beethoven 0.59.
Caveats
Tempo is unknown, so this is not time in seconds. Read with note density.
