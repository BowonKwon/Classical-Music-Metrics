화성 리듬

마디당 화음 기호 수. 주석자가 붙인 화성 분석 기호(로마숫자)를 센다.

공식
화음 기호 수 / 마디 수. 마디 수는 코퍼스 메타데이터의 last_mn(반복 펼치지 않은 마지막 마디 번호).
읽는 법
1이면 마디마다 한 화음, 3이면 3박자 마디에서 박마다 바뀌는 셈이다. 바흐 모음곡 중앙값 3.05, 베토벤 소나타·4중주 1.8.
한계
주석이 있는 코퍼스에만 있다(코랄 제외). 주석자의 분석 단위가 코퍼스마다 조금 다르다.
